# 路线图

这份路线图聚焦 Axiqra 面向生态开放的部分。

## Phase 0: 公开规格

- 发布开源范围和项目 README
- 整理产品和协议文档
- 明确 OSS 维护者使用场景
- 定义贡献和安全规则

## Phase 1: 开放 Schema

- 起草 Case、Solution、Invocation、Feedback、Engineering Trace Package schema
- 增加 JSON 示例
- 增加校验规则
- 增加脱敏要求
- 增加公开工程 Case 样例

## Phase 2: MCP 和 CLI 原型

- 构建最小 MCP server
- 构建 CLI 用于 trace 导入、校验、脱敏和回写
- 增加面向 Codex 的工作流样例
- 增加 schema 校验和脱敏测试

## Phase 3: 维护者工作流

- Issue triage 工作流
- Pull request review 工作流
- Debugging / incident 工作流
- Release / migration 工作流
- Contributor onboarding 工作流

## Phase 4: 审核与治理

- 维护者 review queue
- worked/failed 反馈闭环
- Public Case / Private Case 边界
- 申诉和仲裁工作流
- 可信来源与污染隔离控制
