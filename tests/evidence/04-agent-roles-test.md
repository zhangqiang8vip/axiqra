# Cursor Axiqra MCP 测试任务 - 无历史经验场景

## 测试目标

验证当 `search_before_act` 返回空结果时，Agent 的行为：

1. **作为开发者** - 自己创建代码/方案
2. **作为贡献者** - 调用 `create_seed` 沉淀新经验
3. **作为执行者** - 调用 `submit_trace` 记录过程
4. **作为反馈者** - 调用 `submit_feedback` 评价结果

## 测试任务 1: 有历史经验的场景

```
请帮我分析一个模拟后端问题：登录接口偶发 500。请先看看有没有历史经验可以参考，再给我排查方案，完成后记录一下这次分析过程和结果。
```

**预期行为**:
- Agent 调用 `search_before_act` → 返回历史方案
- Agent 基于方案分析问题
- Agent 调用 `submit_trace` → 记录分析轨迹
- Agent 调用 `submit_feedback` → 反馈方案有效性

## 测试任务 2: 无历史经验的场景 (关键测试)

```
请帮我分析一个全新问题：Rust 异步运行时内存泄漏。请先搜索历史经验，如果没有找到，请作为开发者创建解决方案，完成后把这次分析和解决方案沉淀下来。
```

**预期行为**:
1. Agent 调用 `search_before_act` → 返回空结果
2. Agent **作为开发者** 自己分析并创建方案
3. Agent 调用 `create_seed` → 贡献新经验 (如果是冷门问题)
4. Agent 调用 `submit_trace` → 记录分析过程
5. Agent 调用 `submit_feedback` → 反馈 (not_applicable)

## Agent 双重角色说明

| 角色 | 职责 | 调用工具 |
|------|------|----------|
| **开发者** | 分析问题、创建方案、实现代码 | 自身能力 |
| **贡献者** | 沉淀经验、丰富知识库 | `create_seed` |
| **执行者** | 记录分析过程 | `submit_trace` |
| **反馈者** | 评价方案有效性 | `submit_feedback` |
