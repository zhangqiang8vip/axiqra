# Roadmap / 路线图

## 中文说明

这份路线图聚焦 Axiqra 面向生态开放的部分。

## Phase 0: 公开规格

- 发布开源范围和项目 README
- 整理产品和协议文档
- 明确 OSS 维护者使用场景
- 定义贡献和安全规则

## Phase 1: 开放 Schema

- 起草 Case、Solution、Invocation、Feedback、Engineering Trace Package schema
- 增加 JSON 示例
- 增加校验规则
- 增加脱敏要求
- 增加公开工程 Case 样例

## Phase 2: MCP 和 CLI 原型

- 构建最小 MCP server，用于工程记忆检索
- 构建 CLI，用于 trace 导入、校验、脱敏和回写
- 增加面向 Codex 的工作流样例
- 增加 schema 校验和脱敏测试

## Phase 3: 维护者工作流

- Issue triage 工作流
- Pull request review 工作流
- Debugging / incident 工作流
- Release / migration 工作流
- Contributor onboarding 工作流

## Phase 4: 审核与治理

- 维护者 review queue
- worked/failed 反馈闭环
- Public Case / Private Case 边界
- 申诉和仲裁工作流
- 可信来源与污染隔离控制

---

## English

This roadmap is focused on the open ecosystem-facing parts of Axiqra.

## Phase 0: Public Specification

- Publish open-source scope and project README
- Organize product and protocol documentation
- Clarify OSS maintainer use cases
- Define contribution and security rules

## Phase 1: Open Schema

- Draft Case, Solution, Invocation, Feedback, and Engineering Trace Package schemas
- Add JSON examples
- Add validation rules
- Add redaction requirements
- Add sample public engineering Cases

## Phase 2: MCP and CLI Prototype

- Build a minimal MCP server for engineering memory search
- Build a CLI for importing, validating, redacting, and writing back traces
- Add Codex-oriented workflow examples
- Add tests for schema validation and redaction

## Phase 3: Maintainer Workflows

- Issue triage workflow
- Pull request review workflow
- Debugging and incident workflow
- Release and migration workflow
- Contributor onboarding workflow

## Phase 4: Review and Governance

- Maintainer review queues
- worked/failed feedback loop
- public/private Case boundaries
- appeal and arbitration workflow
- trusted-source and contamination controls
