## 3. 覆盖范围说明

### 3.1 Auth / User 相关

- `AuthController`：登录、注册、登出、当前用户、个人资料更新
- `UserController`：当前用户信息、指定用户公开信息
- `UserServiceImpl`：注册、资料更新、密码校验

### 3.2 Workspace 相关

- 工作空间列表、创建、详情、更新、删除
- 成员列表、添加成员、角色更新、移除成员
- owner / admin 权限分级
- 软删除与乐观锁并发控制

### 3.3 RBAC / ABAC 相关

- `RbacServiceImpl`：owner/admin/member/viewer 判定
- `PolicyEngineServiceImpl`：evaluate / enforce / hasScope
- `PolicyController`：策略评估、强制检查、scope 查询

### 3.4 导航与权限拦截

- `NavServiceImpl`：基础菜单、空间菜单、Scope 菜单、空列表预留
- `ScopeCheckInterceptor`：ANY / ALL 模式
- `WorkspaceRoleCheckInterceptor`：路径参数 / query 参数读取与角色校验
