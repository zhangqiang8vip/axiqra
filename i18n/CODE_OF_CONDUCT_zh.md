# 行为准则

这个项目希望保持有用、谨慎、尊重。

## 期望行为

- 尊重他人，建设性讨论。
- 围绕想法、证据和可维护性反馈。
- 尊重隐私和保密边界。
- 讨论真实工程轨迹时先脱敏。
- 帮助项目对维护者和贡献者更安全。

## 不接受的行为

- 骚扰、侮辱或人身攻击
- 发布 secret 或私有数据
- 未经允许分享客户、仓库或企业内部信息
- 提交误导性证据或无授权复制内容
- 滥用贡献、审核或治理流程

## 执行

维护者可以删除内容、关闭 issue、要求修改、限制参与或升级争议处理。
