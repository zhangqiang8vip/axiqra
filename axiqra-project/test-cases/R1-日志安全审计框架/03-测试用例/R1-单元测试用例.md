## 1. AesEncryptUtil 测试用例

## 3. DataMaskingUtil 测试用例

| 用例编号 | TC-R1-MASK-001 |
|----------|----------------|
| 名称 | maskJson_apiKey |
| 描述 | JSON 中的 api_key 应被脱敏为 SECRET_REDACTED |
| 前置条件 | 无 |
| 输入 | `{"api_key": "sk-1234567890abcdef"}` |
| 预期输出 | 包含 "SECRET_REDACTED"，不含原始密钥 |
| 测试类 | `DataMaskingUtilTest` |

| 用例编号 | TC-R1-MASK-002 |
|----------|----------------|
| 名称 | maskJson_password |
| 描述 | JSON 中的 password 应被脱敏为 PASSWORD_REDACTED |
| 前置条件 | 无 |
| 输入 | `{"password": "MySecretPassword123!"}` |
| 预期输出 | 包含 "PASSWORD_REDACTED"，不含原始密码 |
| 测试类 | `DataMaskingUtilTest` |

| 用例编号 | TC-R1-MASK-003 |
|----------|----------------|
| 名称 | maskJson_internalIp |
| 描述 | 内网 IP（192.168.x.x / 10.x.x.x）应被脱敏 |
| 前置条件 | 无 |
| 输入 | `{"server_ip": "192.168.1.100", "db_ip": "10.0.0.50"}` |
| 预期输出 | 包含 "INTERNAL_IP"，不含原始 IP |
| 测试类 | `DataMaskingUtilTest` |

| 用例编号 | TC-R1-MASK-004 |
|----------|----------------|
| 名称 | maskJson_privateKey |
| 描述 | 私钥内容应被整体脱敏 |
| 前置条件 | 无 |
| 输入 | 包含 `-----BEGIN RSA PRIVATE KEY-----` 的 JSON |
| 预期输出 | 包含 "PRIVATE_KEY_REDACTED" |
| 测试类 | `DataMaskingUtilTest` |

| 用例编号 | TC-R1-MASK-005 |
|----------|----------------|
| 名称 | maskJson_nonSensitive |
| 描述 | 非敏感字段不应被修改 |
| 前置条件 | 无 |

| 预期输出 | 输出等于输入（无修改） |
