## 2. 覆盖率执行命令

```bash
cd D:\ai\axiqra\axiqra-project\axiqra-code
mvn test jacoco:report
```

> 说明：
> - `mvn test` 用于执行全量测试；
> - `jacoco:report` 用于根据测试执行结果生成覆盖率报告；
> - HTML 报告默认输出至 `target/site/jacoco/index.html`；
> - XML 报告通常位于 `target/site/jacoco/jacoco.xml`。
